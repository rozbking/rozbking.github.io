## 📦 Installation Steps

1. **Navigate to your GitHub Pages repo:**
   ```bash
   cd path/to/rozbking.github.io
   ```

2. **Create the aquascaping folder and copy files:**
   ```bash
   mkdir -p aquascaping/guides
   
   # Copy index.html to aquascaping/
   # Copy all files from guides/ to aquascaping/guides/
   ```

3. **Commit and push:**
   ```bash
   git add aquascaping/
   git commit -m "Add Mom's aquascaping birthday gift site 🦐"
   git push
   ```

4. **Site will be live at:** `https://rozbking.github.io/aquascaping/`
